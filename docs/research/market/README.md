# docs/research/market/ — TAM, users, pricing

**Purpose**: Quantitative and qualitative market research that informs business and
positioning decisions. Pricing experiments, TAM/SAM/SOM estimates, user interview
synthesis, segment analysis.

**Per-doc structure**: each file SHOULD declare its methodology (surveys, interviews,
public data, estimation models) so future readers can judge confidence.

**Naming**: `kebab-case-topic.md`. Examples: `pricing-paid-tier.md`,
`indie-dev-segment.md`, `oss-conversion-benchmarks.md`.

**When to add**:
- A pricing decision needs supporting evidence.
- A positioning shift is on the table.
- User interviews surface patterns worth capturing.
- Public benchmarks (e.g., OSS conversion rates) are relevant to a decision.

**What doesn't go here**:
- Per-user feedback or support tickets (those will go in `docs/feedback/` when that folder
  is created).
- Competitor product analysis (use `docs/research/competitive/`).
