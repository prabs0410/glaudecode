# docs/guides/user/ — End-user how-tos

**Purpose**: How-tos for people using GlaudeCode to do their actual work. Install, configure,
run common workflows, connect mobile/web clients, recover from common failures.

**Naming**: `kebab-case-task.md`. Each filename starts with a verb: `install-glaudecode.md`,
`connect-mobile-client.md`, `recover-orphaned-session.md`.

**Tone**: assume a competent developer who has not used GlaudeCode before. Skip background
they already know. Cite the relevant CLI flags and config keys by their exact names.
