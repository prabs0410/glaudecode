## What this branch delivers

**V6 — conversation cockpit (mobile):** the chat-view phone surface, gesture puck, smart upload, the
"everything" nav, the 💬 round-trip toggle, diagnostics HUD.

**V7 — observability layer + post-review hardening** (the founder's "build the monitoring layer first"):
durable engine logs, the EventLog hub + `diagnostics()` RPC + APM, the phone→Mac error pipe, the Mac
diagnostics panel + phone Debug tab, audit UI. Plus the post-review fixes: session-inference tiebreaker,
**RPC scope default-DENY** (not fail-open), gate-run mirror-drift battery, `/upload` streaming byte-counter,
model-match longest-key-first, **desktop safety-UI tests** (kill-switch/arm/consent), served-page
option-selection behavioral coverage, a docs-drift audit — and a **repair of the verify gate**, which had
been a silent no-op (`bun --cwd … run …` printed help + exited 0) since it was introduced.

**V8 — away-mode push · token durability · security groundwork:**
- **Web Push, end-to-end built** (delivery gated on HTTPS): a hand-rolled VAPID + RFC 8291 `aes128gcm`
  sender (no `web-push` dep), the approval trigger ("Claude is blocked waiting for you" → your phone
  buzzes), a service worker, the "🔔 Enable alerts" subscribe flow, committed PWA/notification icons.
- **C1 — HMAC-signed tokens + a persisted device roster**, so a paired phone **survives an engine
  respawn** instead of being logged out; revocation also survives a respawn. Still no token at rest (only
  the signing key + device metadata persist). No Rust change.
- **WS4 — seamless-pairing threat-model** (decision doc; staged conditional-GO — device-bound tokens are
  the remaining gate before a 30-day terminal token).
